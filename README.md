# Capacitance Measurement System on STM32G474RE

This project measures an **unknown capacitance** by exciting an **RC circuit** with a PWM signal and measuring the **time constant (τ = R·C)** using STM32 timers plus an analog comparator + DAC threshold.

> Board / MCU: **STM32G474RE** (STM32G4 series)

## Concept (high level)

1. **Generate a PWM excitation** (square wave) with **TIM1 Channel 1**.
2. Feed that PWM through a known **resistor R** into the **unknown capacitor C** (RC charging curve).
3. Turn the capacitor voltage **Uc** into a digital edge by comparing it to a fixed threshold using:
   - **DAC** generates a reference voltage corresponding to ~**0.6 · 3.3 V ≈ 1.98 V** (adjust to your chosen threshold)
   - **Comparator** compares **Uc** (+ input) against DAC reference (− input)
   - Comparator output becomes a **square signal** that toggles when **Uc** crosses the threshold
4. Use **TIM2** in **Input Capture** mode to measure the delay between:
   - the PWM edge (start)
   - the comparator edge (threshold reached)

That measured delay is directly related to the RC time constant, so with known **R** you can compute **C**.

## How the measurement works

### Signals
- **PWM (excitation)**: generated by **TIM1 CH1** and applied to the RC network.
- **Comparator output**: goes high when **Uc** rises above the DAC threshold.

### TIM2 configuration
TIM2 uses **two input capture channels**:

- **TIM2 CH1**: Input Capture, direct mode (connected to the PWM)
- **TIM2 CH2**: Input Capture, direct mode **from remap** (connected to comparator output)

TIM2 is configured as:
- **Slave mode**: **Reset mode**
- **Trigger source**: **TI2FP2**

Meaning: every time the PWM trigger occurs, TIM2 counter is reset, then TIM2 captures until it detects the rising edge from the comparator output.

### What is measured? (equations)

Let **Td** be the time from the PWM edge to the moment **Uc** reaches the threshold.

For an RC charging curve:

```
Uc(t) = VDD · (1 − e^(−t/(R·C)))
```

If the comparator threshold is **Vth**, then:

```
Vth = VDD · (1 − e^(−Td/(R·C)))
```

Solving for **Td**:

```
Td = −R·C · ln( 1 − Vth/VDD )
```

If you choose **Vth = VDD/2**, it simplifies to:

```
Td = R·C · ln(2)
```

So:

```
C = Td / ( R · ln(2) )
```

## Hardware overview

- **TIM1 CH1**: PWM output to RC input
- **R**: known resistor
- **C**: unknown capacitor (sensor / plates / material under test)
- **DAC**: generates **Vth**
- **COMP**: compares **Uc** to **Vth**
- **TIM2**: captures timing (PWM reference + comparator edge)

## Typical workflow

1. Configure peripherals (TIM1 PWM, DAC threshold, COMP, TIM2 input capture + slave reset).
2. Start PWM.
3. For each PWM cycle:
   - TIM2 resets on the trigger
   - TIM2 captures the rising edge of comparator output
   - Compute **Td** from captured counts and timer clock
4. Compute **C** using the selected threshold formula.

## Notes / calibration

- The accuracy depends on:
  - resistor tolerance (use a precision resistor)
  - timer clock accuracy
  - comparator/DAC accuracy and chosen threshold
  - PWM frequency (must allow enough time for charge/discharge)
- If you use a threshold other than **VDD/2**, use the general equation above.
